# Face samples

Jarvis uses the filename (without its extension) as the recognized person's name.
For example, `AlexExample.jpg` is displayed as `AlexExample`.

To enroll yourself:

1. Add one clear, front-facing JPG or PNG portrait here.
2. Name it after the person, such as `JaneDoe.jpg`.
3. Start Jarvis. It creates a local encoding in `../images-encodings/`.

Personal images and generated encodings are ignored by Git. `AlexExample.jpg` is
the only committed sample and depicts a synthetic, non-identifiable person generated
for this project.
